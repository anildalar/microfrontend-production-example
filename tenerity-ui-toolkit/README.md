# tenerity-ui-toolkit

> Tenerity UI Toolkit for all UI Apps

[![NPM](https://img.shields.io/npm/v/tenerity-ui-toolkit.svg)](https://www.npmjs.com/package/tenerity-ui-toolkit) [![JavaScript Style Guide](https://img.shields.io/badge/code_style-standard-brightgreen.svg)](https://standardjs.com)

## Install

```bash
npm install --save tenerity-ui-toolkit
```

## Usage

```jsx
import React, { Component } from 'react'

import MyComponent from 'tenerity-ui-toolkit'
import 'tenerity-ui-toolkit/dist/index.css'

class Example extends Component {
  render() {
    return <MyComponent />
  }
}
```
